# MH Fitness Website

A multi-page gym website created from scratch for a student website design assignment using HTML and CSS only.

## Pages (14)
1. Home (`index.html`)
2. About Us (`about.html`)
3. Programs (`programs.html`)
4. Trainers (`trainers.html`)
5. Schedule (`schedule.html`)
6. Membership (`membership.html`)
7. Pricing (`pricing.html`)
8. Nutrition & Recovery (`nutrition.html`)
9. Member Stories (`transformation.html`)
10. Gallery (`gallery.html`)
11. Fitness Journal (`blog.html`)
12. Journal Article (`blog-details.html`)
13. FAQs (`faq.html`)
14. Contact (`contact.html`)
15. Join Us (`join.html`)

## Run locally
Open `index.html` in a browser. All pages share `style.css`.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `mh-fitness-website`.
2. Upload all HTML files and `style.css` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. Your live URL will be shown in Settings → Pages.

## Notes
- The forms are front-end demonstrations only; they do not send or save information.
- Photos are loaded from Unsplash and require an internet connection.
- Pricing, timetable, contact information, trainer profiles, and member stories are illustrative placeholders. Update them before any real-world use.
